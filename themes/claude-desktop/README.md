# Claude Desktop theme

`t3-code-claude-desktop.json` is a T3 Code theme, "T3 Code Claude", with Claude Desktop's neutral greys with the clay accent in light and dark.
To use it, open Settings → Appearance → Add theme and import the JSON file.
To regenerate it, edit `make_claude_desktop.py` and run `python3 -I themes/claude-desktop/make_claude_desktop.py` from the repo root; it rewrites the JSON from `t3-code-claude.json`.
